===============================================
   GIT И GITHUB – ШПАРГАЛКА (Windows/PowerShell)
===============================================
==================================================================
 git push origin main
===================================================================

1. БАЗОВЫЕ КОМАНДЫ
------------------
git status                    – показать состояние репозитория (изменения)
git add <файл>                – добавить файл в индекс (подготовить к коммиту)
git add .                     – добавить все изменения (новые, изменённые) в индекс
git commit -m "сообщение"     – создать коммит с сообщением
git commit                    – открыть редактор для ввода сообщения коммита

2. РАБОТА С УДАЛЁННЫМ РЕПОЗИТОРИЕМ (GitHub)
-------------------------------------------
git remote -v                 – показать адреса удалённых репозиториев
git remote set-url origin <url> – изменить URL удалённого репозитория
git push origin main          – отправить локальную ветку main в удалённый репозиторий
git push -u origin main       – отправить и установить связь (upstream) для текущей ветки
git push                      – отправить текущую ветку в настроенный удалённый репозиторий
git pull origin main          – скачать изменения из удалённой ветки и слить с локальной
git fetch                     – скачать изменения без слияния

3. ВЕТКИ
--------
git branch                    – список локальных веток (текущая помечена *)
git branch -a                 – список всех веток (включая удалённые)
git branch <имя>              – создать новую ветку
git checkout <имя>            – переключиться на другую ветку
git switch <имя>              – то же, что checkout (новый синтаксис)
git branch -m <старое> <новое> – переименовать ветку
git branch -d <имя>           – удалить локальную ветку (если слита)
git branch -D <имя>           – принудительно удалить локальную ветку
git push origin --delete <имя> – удалить ветку на GitHub

4. УДАЛЕНИЕ ФАЙЛОВ ИЗ ИНДЕКСА (если случайно добавили)
------------------------------------------------------
git rm --cached <файл>        – убрать файл из индекса, но оставить локально
git rm -r --cached <папка>    – убрать папку из индекса рекурсивно

5. ИГНОРИРОВАНИЕ ФАЙЛОВ (.gitignore)
-----------------------------------
- Создать файл .gitignore в корне и перечислить в нём шаблоны.
- Пример: 
  build/
  .gradle/
  .idea/
  *.log
- После добавления .gitignore, если файлы уже отслеживались, выполнить:
  git rm -r --cached <папка> 
  git add .gitignore
  git commit -m "Add .gitignore"
  git push

6. ОТКАТ ИЗМЕНЕНИЙ
------------------
git restore <файл>            – отменить изменения в рабочем каталоге (не сохранённые)
git reset HEAD <файл>         – убрать файл из индекса (но изменения останутся)
git reset --soft HEAD~1       – отменить последний коммит, оставив изменения в индексе
git reset --hard HEAD~1       – отменить последний коммит и удалить изменения (осторожно!)

7. РАБОТА С КОНФЛИКТАМИ
----------------------
При конфликте после pull:
- Исправить файлы вручную, затем:
  git add .
  git commit -m "Merge resolved"
  git push

8. ПОЛНЫЙ ЦИКЛ ПУША (с момента внесения изменений)
------------------------------------------------
git status                    # проверить, что изменено
git add .                     # добавить все изменения
git commit -m "Ваше сообщение" # создать коммит
git push origin main          # отправить на GitHub

9. ЕСЛИ ВОЗНИКЛА ОШИБКА "non-fast-forward"
-----------------------------------------
- Если хотите перезаписать удалённую ветку (потеряете изменения на GitHub):
  git push -f origin main
- Если хотите объединить истории (с pull):
  git pull origin main --allow-unrelated-histories
  # разрешить конфликты, затем commit и push

10. ПОЛЕЗНЫЕ ДОПОЛНИТЕЛЬНЫЕ КОМАНДЫ
----------------------------------
git log --oneline             – краткая история коммитов
git diff                      – показать различия между рабочим каталогом и индексом
git stash                     – временно спрятать изменения
git stash pop                 – вернуть спрятанные изменения
