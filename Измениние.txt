- Created PermissionUtil.java – a unified centralized permission checking class that considers:
    • admin-user from Settings/main.yml (via AdminManager)
    • regionmc.* permission
    • regionmc.admin permission
    • OP (isOp())
    • individual permissions (e.g., regionmc.command.reload)

- Added extended diagnostics for loading main.yml in AdminManager.java (path, size, keys output) and reload() method.

- Introduced methods in RegionCommand.java:
    • hasBasicAccess(CommandSender) – always true for console, checks admin-user, regionmc.*, regionmc.admin, OP for players.
    • hasPermission(CommandSender, String) – always true for console, uses PermissionUtil for players.
  Added console support – now the console can execute all commands without restrictions.

- Made getDefaultLimit() method public in RegionManager.java (was private) for access from RegionCommand (/regionmc limit command for console).

- Added CommandSender support to all subcommands (commands.subcommands package) – they now correctly handle console calls.

- Fixed execute signatures in RegionFlagCommand and RegionExampleCommand to support CommandSender.

- Added admin-user section to main.yml (Settings/main.yml) with example:
    # =============================================
    # Plugin administrators (all permissions)
    # disable or remove nickname from the list
    # all permissions are granted (be careful with nicknames)
    # =============================================
    admin-user:
      - "KillerYTuber1" # Creator's nickname
      - "Neonix98"      # Test creator's nickname
      - #"player"       # Nickname is not working (Commented out)

- Added ability to enter commands from the console – all commands are now available from console input.
```
